ECONOMICS ADVENTURE GAME
========================

A city exploration game about economics, work, and life skills.

HOW TO RUN THE GAME:
--------------------
1. Make sure Python 3 is installed on your computer
2. Double-click "run_game.py" or run: python3 run_game.py
3. The game will automatically install required packages if needed

CONTROLS:
---------
- WASD or Arrow Keys - Move around the city
- E - Interact with buildings and objects
- G - Toggle grid view
- ESC - Exit buildings / Return to menu
- F12 - Take screenshot

GAMEPLAY:
---------
- Follow objectives shown at the top of the screen
- Enter buildings by walking to them and pressing E
- Complete mini-games and activities to earn money
- Make economic decisions that affect your progress
- Learn about budgeting, work, and financial literacy

REQUIREMENTS:
-------------
- Python 3.7 or higher
- pygame 2.5.2 (will be installed automatically)

TROUBLESHOOTING:
----------------
If the game doesn't start:
1. Install Python from python.org
2. Open terminal/command prompt
3. Navigate to game folder
4. Run: pip install pygame==2.5.2
5. Run: python3 run_game.py

Enjoy the game!
